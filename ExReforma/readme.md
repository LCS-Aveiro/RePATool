# ReForma 

**ReForma** (Reconfigurable Formal Automata) is a Python library that bridges the gap between **Formal Methods** and **Data Science**. 

With ReForma, you can extract automata directly from event logs, train transition probabilities based on real user behavior, and analyze the dynamic rules of your system.

##  Installation

To use ReForma and its data extraction features, you need to install the library along with `pandas`:

```bash
pip install reforma pandas
```

*(Optional: If you want to render static offline graphs, you should also install `networkx` and `matplotlib` by running `pip install networkx matplotlib`)*.
